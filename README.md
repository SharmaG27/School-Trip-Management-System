# School Trip Management System

## Project Overview
This is a full-stack desktop application I made for my comprehensive school to use. I built this because I wanted to learn how to implement features in a .NET framework and give back to my school.

## Key Features
* Feature 1: Has 4 user access levels (admin, receptionist, teacher, student). Users can create/sign up/delete/manage trips depending on their assigned access level. 
* Feature 2: Uses encrypted .txt files as a fully relational database structre (3NF) to manage user login and personal details. 
* Feature 3: Implemented extensive validation/verification as well as a well-structured and intuitive user interface to suit users of all ages. 

## Tech Stack
* **Language:** Visual Basic
* **Framework:** .NET / Windows Forms
* **IDE:** Microsoft Visual Studio
